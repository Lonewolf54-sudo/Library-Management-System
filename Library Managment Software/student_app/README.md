# The Archive - Student App

Flutter prototype for the Student mobile app.

Primary flow:

`Login -> Home -> Explore -> Virtual Bookshelf -> Select Book -> Floating Preview -> Open Book -> Borrow Duration -> Pickup Pass -> My Shelf`

The current app uses local mock data only. Backend, admin portal, and librarian portal are intentionally not included yet.
